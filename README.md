# Wage_gap
Project Overview

This project visualizes global gender salary disparities using an interactive, year-switchable bar chart built with D3.js v7.  Users can:

1. Click the year button to view the data of each year
2. Hovering the mouse over each column can display the salary situation and salary gap between men and women in various countries.
3. Hovering the mouse over each column can display a simple line chart of salary gaps in various countries from 2015 to 2024
4. Clicking on the color legends "female" and "male" can display the data of each gender. Clicking on the blank Spaces will deselect them.
